Protocolo

Cada run mantém um registro auditável.

Resolve fixa uma revisão imutável e contexto escopado. Execute produz evidência. Approval vincula uma pessoa ao artefato verificado. Publish e finalize retomam com segurança após interrupções.

Limite de execução

Mantenha os efeitos do agente dentro de limites explícitos.

Hooks e skills são a superfície esperada para o agente. Pajé mantém estado durável, identidade do artefato, verificação, aprovação e publicação atrás de portas Go neutras ao provedor.

Escopo do beta

O que o beta oferece.

O template embutido code-change@v1 roda pelo Hatchet. O modo artifact é padrão. O modo pull request adiciona aprovação vinculada ao artefato e publicação idempotente de rascunho no GitHub. Codex é o primeiro harness suportado.
